# Photoshop 蓝湖功能对照 · 0.6.17 隔离试用

对照范围：仓库固定的蓝湖 Photoshop UXP **1.0.32（303）**，以 [固定构建校验](../compatibility.json) 和原版包中登录、项目、设置、切图及上传结果组件为准；[蓝湖 Photoshop 帮助教程](https://lanhu.100tal.com/sos/lan-hu-xiang-xi-jiao-cheng.html#21-%E5%AE%89%E8%A3%85%E6%8F%92%E4%BB%B6) 用于核对基础使用流程。不把旧 CEP 教程里的选项当成当前 UXP 承诺。

## 基础功能已接入

- **账号**：浏览器授权（含等待、取消、超时）、普通账号密码、退出并清理当前会话的去向数据。使用本插件独立会话，不读取已安装官方插件的登录存储。
- **上传**：读取团队、项目和分组（含项目根目录），选择原版平台/设计倍数和全部/选中范围，使用原版上传流程。新布局显示当前去向、实际画板列表和底部数量；明确选择了选中范围但为空时不全传。无画板结构的 PSD 仍由原版画板读取逻辑提供上传条目。
- **切图**：标记选层、创建切图分组、取消标记、显示/隐藏区域；仍委托原版 Photoshop 方法。隐藏区域不是删除切图。预设切图、标注和下载是否与原版一致，需要在蓝湖网页对照同一稿件的结果。

## 尚未完整复刻

- **登录分支**：没有原版换登录场景后可能出现的验证码表单和「忘记密码」入口。浏览器自身的登录、验证码或单点登录由蓝湖网页处理，不等于插件内支持这些分支。
- **项目管理与权限**：只能选现有团队、项目和分组；没有原版的新建云端项目/分组。当前只允许上传到固定隔离测试项目，非测试项目只显示禁用，不是权限兼容问题，也不应通过改 UI 绕过。
- **设置和网页跳转**：未复刻原版主题切换、版本更新/下载、帮助中心、「前往蓝湖」及结果页的网页查看入口。退出登录已接入；面板也不负责启动另一份官方插件。原包有其它条件式设置实现，但不把代码分支等同于此原版环境已启用的功能。
- **上传结果和恢复**：目前显示进度与汇总，不呈现原版的逐画板队列、失败列表及可操作的失败原因。没有原版的失败项重试、无变化时「仍然上传」或自动查云端修订。部分成功与结果不明提示先人工核对，不提供整批重传捷径。
- **旧版 SVG / 快速上传**：教程中的 Photoshop v2.38 生成器选项不是本次固定 UXP 包的可见设置；本插件无这些开关，不能据此断言原版 UXP 的实际矢量输出行为。本次未验证 SVG 结果。

## 真机确认与范围限制

- 2026-11-18，0.6.16 在 Photoshop 28 对隔离项目根目录的两份合成副本做了实传及原版 1.0.32（303）回读对照，均为 iOS @3x。画板 B 的候选 V3 与原版 V4 标注一致，188×92 预览解码 RGBA 逐像素一致。无画板带切图稿的候选 V2（选中）、V3（全部）与原版 V4 的三档源 PNG 逐字节一致，三版均出现网页标注高度 124 px、@3x 文件高度 125 px。原版使用单独的 UDT 开发登记，上传业务文件与固定原包一致。完整云端 JSON、文字属性和复杂层级仍待覆盖。
- 九宫格导出按原版实际选传清单和 PSD 原生图层树处理。普通画板沿用原生数据；每张有标记的画板仅携带本画板的节点及引用的资源版本。同一版本跨画板保持相同 `assetRef`，各自引用由同一份原始快照提供的 1× 源节点。图层归属、实际选传范围或源快照无法验证时，本批导出失败。
- 旧的无原生画板文档沿用已有 XMP `artboardId`。原生画板的 GameUI 身份由持久 `documentId` 与 PSD 原生画板图层 ID 共同确定。旧 XMP 只有单一文档级 `artboardId`，缺少它与既有原生画板修订的绑定凭证。已有这类修订时，身份迁移需要独立核对。
- 混合与多画板目前通过冻结原包模块的本地测试，仍需 Photoshop 实传、蓝湖回读与 Unity 导入验证。多画板稿含无法按画板分配的根级 GameUI 字段时会明确拒绝标记画板导出；扩展字段的作用域和往返验收仍按验收标准办理。
- 多画板导出接受已有九宫格标记。当前九宫格面板仍拒绝在原生画板内部创建源或应用实例，合成稿应预先准备有效标记。
- 推广前按 [PS 上传验收标准](PS-UPLOAD-ACCEPTANCE-STANDARD.md) 验证真实 Photoshop 登录/切图、蓝湖回读、Unity 导入，以及安装、卸载和回退。保留独立的官方插件作为正式流程，不用此试用版替代。
